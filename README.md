# Discount Calculator

A simple and clean discount calculator built with React and Bootstrap.

This project allows users to enter an original price and discount percentage to quickly calculate the final price and see how much they save.

### Features

- Calculate discounted price
- Calculate total savings
- Simple and beginner-friendly interface
- Clear button to reset the calculator
- Responsive design using Bootstrap
- React state management with `useState`
- React Router navigation
- Clean and minimal layout

### Built With

- React
- JavaScript
- Bootstrap
- React Router

### How It Works

Enter the **original price** and **discount percentage**, then click **Calculate**. The calculator displays the final price and the amount saved.

This project was created as a simple React practice project focused on learning components, state management, event handling, and basic calculations.
